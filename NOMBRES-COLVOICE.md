# ColVoice

La marca pública de este proyecto es **ColVoice** y su descriptor es **Voz Colombiana**.

El nombre combina “Col”, por Colombia y el contexto latinoamericano, con “Voice”, para que sea fácil de entender y encontrar fuera del país. La interfaz y la documentación mantienen el nombre del motor interno `omnivoice` únicamente para conservar compatibilidad con el proyecto upstream.

ColVoice se presenta como una solución local y abierta para generación, clonación, almacenamiento y transformación de voces con español colombiano, mexicano y latinoamericano.
