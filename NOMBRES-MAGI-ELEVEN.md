# Ideas de nombre

La marca aplicada en la interfaz es **MAGI Eleven Studio** y su forma corta es **MAGI Eleven**.

Opciones derivadas de `MAG` + `iEleven`:

1. **MAGI Eleven Studio** — recomendada; suena natural, conserva las dos raíces y funciona para una herramienta creativa.
2. **MAG Eleven** — directa y fácil de recordar.
3. **MAGiEleven** — más tecnológica y cercana a la combinación original.
4. **MAG Eleven Voice** — clara para posicionar el producto como solución de voz.
5. **MAGI Eleven Local** — destaca privacidad y procesamiento en el equipo.
6. **MAGI Eleven Colombia** — útil si el enfoque principal será el acento y contenido colombiano.

La marca no cambia el paquete Python interno `omnivoice`, porque ese nombre pertenece a la implementación base y cambiarlo rompería imports, scripts y compatibilidad con el motor upstream.
